# 3D Starter

A small, asset-free 3D project that opens directly into a lit cube scene.

## Try this

1. Open `Scenes/Main.yaml` in the editor.
2. Select the cube and move, rotate, or scale it in the Inspector/viewport.
3. Change the Sun's intensity or rotate it to see the lighting change.
4. Duplicate the cube, save the scene, and press Play.

The cube uses Overcore's built-in `Cube` mesh and `White` texture, so this project needs no downloads or imported assets. The project is yours to edit; the bundled template remains unchanged.
