# UI Showcase

A compact, asset-free UI project that opens on a responsive Canvas. It includes English and Arabic/Persian text, a pointer-interactive button, and a keyboard-editable input field.

## Try this

1. Open `Scenes/Main.yaml` to inspect the Canvas and its child RectTransforms.
2. Resize the viewport and watch the layout scale.
3. Hover and press the button to see its state tint.
4. Click the input field and type in English or Arabic/Persian; try the arrow keys to move through right-to-left text.
5. Change the text, anchors, or colors and save your copy.

The button demonstrates interaction feedback only; it has no gameplay callback attached. The project uses the engine's bundled fonts and solid-color Images, so it needs no downloaded assets. Its source template stays untouched when you create a copy.
